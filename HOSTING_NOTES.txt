ZeroCard — заливка (мультиязычные поддиректории + пре-рендер блога)
===================================================================

Структура dist:
  index.html              -> RU главная (/)
  en|de|es|pt|it|fr/index.html -> главные на языках (/en, /de, /es, /pt, /it, /fr)
  blog/index.html         -> RU блог (/blog)
  en|de|es|pt|it|fr/blog/index.html -> блог на языках (/en/blog и т.д.)
  blog/<slug>/index.html            -> RU статьи (готовый HTML)
  <lang>/blog/<slug>/index.html     -> статьи на языках
  assets/, sitemap.xml, robots.txt, .htaccess, _redirects

Каждая языковая страница (главная, индекс блога, статья) — ГОТОВЫЙ HTML
на своём языке: заголовки, текст, meta, canonical, hreflang, Schema.org.
Краулеры сразу видят контент.

Заливка
-------
Всё содержимое dist в корень сайта (public_html), включая подпапки
en/ de/ es/ pt/ blog/ и скрытые .htaccess и _redirects.

ВАЖНО про блог (динамический контент)
-------------------------------------
Статьи берутся из Supabase и пре-рендерятся В МОМЕНТ СБОРКИ. Значит:
  - Все статьи, что есть в базе на момент `npm run build:ssg`, попадают
    в статический HTML (лучший вариант для поиска).
  - Статьи, добавленные ПОСЛЕ сборки, будут работать как SPA (клиентский
    рендер) и попадут в пре-рендер/sitemap только после следующей сборки.
  => Пересобирай (`npm run build:ssg`) и перезаливай после публикации
     новых статей, либо повесь это на CI/крон после автогенерации.

Пересборка одной командой (на машине с доступом в интернет):
  npm install
  npm run build:ssg
(делает: sitemap -> client build -> SSR build -> prerender -> чистит dist-server)

Apache (REG.RU, Timeweb): .htaccess уже настроен
  - /de, /de/blog, /de/blog/<slug> отдаются как готовые файлы
  - несуществующие статьи -> индекс блога языка -> дальше SPA
  - старые /?lang=de -> 301 на /de
Nginx / Netlify: см. _redirects и правила try_files (как для главных).

Проверка на СТЕЙДЖИНГЕ до прода (обязательно)
--------------------------------------------
  1. /de, /en, /es, /pt, /it, /fr — исходник страницы: <html lang="xx"> и текст на языке.
  2. /de/blog — открывается индекс блога на немецком.
  3. Любая статья /de/blog/<slug> — в исходнике заголовок и текст статьи,
     og:type=article, Article-разметка.
  4. F5 на любой из этих страниц не даёт 404.
  5. sitemap.xml содержит /, /en.., /blog, /en/blog.. и статьи.

После заливки добавь sitemap.xml в Google Search Console и Яндекс.Вебмастер.
Индексация новых языков/страниц — недели-месяцы.
